# Basic example

The `useDropzone` hook just binds the necessary handlers to create a drag 'n' drop zone.
Use the `getRootProps()` fn to get the props required for drag 'n' drop and use them on any element.
For click and keydown behavior, use the `getInputProps()` fn and use the returned props on an `<input>`.

Furthermore, the hook supports folder drag 'n' drop by default. See [file-selector](https://github.com/react-dropzone/file-selector) for more info about supported browsers.

<Basic />

```tsx
import React from "react";
import {useDropzone} from "react-dropzone";

function Basic() {
  const {acceptedFiles, getRootProps, getInputProps} = useDropzone();

  const files = acceptedFiles.map(file => (
    <li key={file.path}>
      {file.path} - {file.size} bytes
    </li>
  ));

  return (
    <section className="container">
      <div {...getRootProps({className: "dropzone"})}>
        <input {...getInputProps()} />
        <p>Drag 'n' drop some files here, or click to select files</p>
      </div>
      <aside>
        <h4>Files</h4>
        <ul>{files}</ul>
      </aside>
    </section>
  );
}
```

## Removing files

<RemovableFiles />

Use `removeFile(file)` with a File object from `acceptedFiles` or `fileRejections` to remove that
file from the hook's state. Matching uses object identity, so different files with the same name
are kept separate. An unknown file is ignored. Use `clearFiles()` to clear both lists and reset
the native input. It also discards pending file reads or validation results, so they cannot
restore the cleared files.

```tsx
const {acceptedFiles, removeFile, clearFiles} = useDropzone();

<ul>
  {acceptedFiles.map((file, index) => (
    <li key={index}>
      {file.name}
      <button type="button" onClick={() => removeFile(file)}>
        Remove
      </button>
    </li>
  ))}
</ul>;
<button type="button" onClick={clearFiles}>
  Clear files
</button>;
```

Neither method fires `onDrop`, `onDropAccepted`, or `onDropRejected`. They only change the hook's
file state; they do not cancel uploads or update file lists stored separately by your application.
`removeFile` does not change the native input's `FileList`; submit the remaining `acceptedFiles`
when building an upload request. Both methods are also available through `<Dropzone>` render props.
